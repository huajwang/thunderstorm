# Build Your First AI Computer Vision System

**Teach a computer to see.**

Learning journey:

```text
Camera → Computer Vision → AI → Decision → Action
```

This repository is a 6-week, 20-program course for ages 13–17. Students eventually build an AI-powered smart security system.

## Start here

1. Install Python 3.10+
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Begin with Week 1:

```bash
cd week01-camera
python 01_open_camera.py
```

## Course map

| Week | Focus | Status |
|------|--------|--------|
| 1 | Camera + OpenCV fundamentals | Programs 01–08 ready |
| 2 | Object detection with YOLO | Programs 09–12 ready |
| 3 | Real-time AI decisions | Programs 13–16 ready |
| 4 | AI + Arduino hardware | Programs 17–19 ready |
| 5 | Student project | Program 20 ready |
| 6 | Demo Day | Checklist + presentation guide ready |

## Final project entry point

```bash
cd week05-project
python 20_smart_security_starter.py
```

Edit the **SETTINGS** block at the top of Program 20 to remix your own system.
