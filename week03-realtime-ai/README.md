# Week 3 — Real-Time AI Vision

**Big idea:** Live AI is not only about *what* is detected — it is also about *how fast*, *how sure*, *how many*, and *what decision* your program makes.

**This week’s pipeline:**

```text
Camera → YOLO → filter/threshold/count → Decision (ALERT / CLEAR)
```
