# Demo Day Presentation Guide (2–3 minutes)

## Script scaffold

**1. Hook (15 seconds)**  
“I built an AI system that can see ______ and then ______.”

**2. Camera (20 seconds)**  
“Here is the live camera. This is the input.”

**3. AI (30 seconds)**  
“YOLO detects objects. I care about: ______.  
You can see the boxes and confidence scores.”

**4. Decision (30 seconds)**  
“When the rules are met, my program decides: ______.  
Otherwise it stays: ______.”

**5. Action (30 seconds)**  
“That decision triggers ______ (LED / buzzer / on-screen alarm).”

**6. My change (30 seconds)**  
“I changed ______ because ______.  
Now the system is a ______ instead of only a generic person alarm.”

**7. Close (15 seconds)**  
“The full path is Camera → AI → Decision → Action.”

## Tips

- Face the audience; glance at the screen to point.
- Do not narrate every line of code — show the behavior.
- If something fails, say what you expected and switch to backup mode calmly.
