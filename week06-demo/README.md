# Week 6 — Demo Day

No new coding program. Students demonstrate the system they customized in Week 5.

## Goals

Each student (or team) shows:

1. What the camera sees  
2. What AI detects  
3. What decision the program makes  
4. What physical action happens (or on-screen action if no hardware)  
5. What they changed themselves

- `demo_checklist.md` — run-through before presenting
