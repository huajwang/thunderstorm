# Week 1 — Camera + Computer Vision Fundamentals

**Big idea:** A camera gives the computer images. A video is a sequence of images called **frames**. Python and OpenCV can process those images.

**This week’s pipeline:**

```text
Camera → Frames → Capture → Process → Overlay → Snapshot Station
```

No YOLO. No neural networks. Just seeing and changing images.

---

## Programs

| # | File | What you learn |
|---|------|----------------|
| 01 | `01_open_camera.py` | Open the webcam and see yourself |
| 02 | `02_frame_loop.py` | Video is a loop of frames |
| 03 | `03_capture_photo.py` | Save a photo with a keypress |
| 04 | `04_grayscale.py` | Turn color into gray |
| 05 | `05_resize.py` | Make images smaller |
| 06 | `06_crop_roi.py` | Focus on one region (ROI) |
| 07 | `07_draw_overlay.py` | Draw boxes and text (HUD) |
| 08 | `08_snapshot_station.py` | Mini project — Snapshot Station |

**Week 1 complete** when Program 08 works and students can explain:

> A camera gives the computer images. A video is frames. Python/OpenCV can process, annotate, and save those images.
